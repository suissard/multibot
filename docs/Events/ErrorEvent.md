# `ErrorEvent`

> **Classe :** `ErrorEvent` (hérite de `Event`)

> **Identifiant :** `error`

> **Description :** Affiche les erreurs de discord.js.

### Méthode `handleEvent(error)`

Gère l'événement 'error' de discord.js. Affiche l'erreur dans la console.

**Paramètres :**

| Paramètre | Type | Description |
| :-------- | :--- | :---------- |
| `error` | <span class="badge badge-type">Error</span> | - L'objet Erreur fourni par l'événement. |
