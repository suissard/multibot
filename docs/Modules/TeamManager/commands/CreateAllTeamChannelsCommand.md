# `CreateAllTeamChannelsCommand`

> **Description :** Lance la création/synchronisation de tous les salons d'équipe pour un segment donné.

## Arguments

| Paramètre | Type | Description | Obligatoire |
| :-------- | :--- | :---------- | :---------- |
| `segment` | <span class="badge badge-type">STRING</span> | Le nom du segment à synchroniser (Optionnel). | <span class="badge badge-optional">Optionnel</span> |
