# `OlympeMember`

> **Classe :** `OlympeMember`

## Classe : `OlympeMember`

Représente un membre d'une équipe dans le contexte de l'API Olympe.

### Constructeur `new OlympeMember(user, tags, roles)`

**Paramètres :**

| Paramètre | Type | Description |
| :-------- | :--- | :---------- |
| `user` | <span class="badge badge-type">OlympeUser</span> | - L'objet utilisateur Olympe associé à ce membre. |
| `tags` | <span class="badge badge-type">object</span> | - Les tags associés au membre, comme les rôles en jeu. |
| `roles` | <span class="badge badge-type">Array<string></span> | - Les rôles administratifs ou de statut du membre dans l'équipe (ex: 'captain'). |
