# `MultiBotMessageEmbed`

## Classe : ``

Une classe wrapper pour `discord.js/EmbedBuilder` afin de fournir une interface personnalisée.

**Paramètres :**

| Paramètre | Type | Description |
| :-------- | :--- | :---------- |
| `title` | <span class="badge badge-type">string</span> | - Le titre initial de l'embed. |
| `description` | <span class="badge badge-type">string</span> | - La description initiale de l'embed. |
